## 解题思路 / Approach

### 题目 1：两数之和 (Two Sum)

**题意理解：**  
给定整数数组 `nums` 和目标值 `target`，找出数组中两个数下标，使其之和等于 `target`。

**思路：**  
1. 使用哈希表记录已遍历的数字及其下标。
2. 对每个数字 `num`，检查 `target - num` 是否已在哈希表中。
3. 若存在，直接返回两个下标；否则将当前数字存入哈希表。

**复杂度分析：**
- 时间复杂度：O(n) — 只需遍历一次数组
- 空间复杂度：O(n) — 哈希表最多存储 n 个元素

**代码：**

```python
def twoSum(nums: list[int], target: int) -> list[int]:
    seen = {}  # value -> index
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []
```
