## 📁 Repository Structure / 仓库结构

```
My_-algorithm_notes/
├── README.md                  # 仓库说明 / Repository overview
├── daily/                     # 每日笔记 / Daily notes (organized by date)
│   └── YYYY-MM-DD.md
├── topics/                    # 专题笔记 / Topic-based notes
│   ├── sorting/               # 排序算法 / Sorting algorithms
│   ├── searching/             # 搜索算法 / Searching algorithms
│   ├── dynamic-programming/   # 动态规划 / Dynamic programming
│   ├── graphs/                # 图算法 / Graph algorithms
│   ├── trees/                 # 树结构 / Trees & tree algorithms
│   ├── strings/               # 字符串 / String algorithms
│   └── data-structures/       # 数据结构 / Data structures
└── templates/                 # 笔记模板 / Note templates
    └── daily-template.md
```

---

## 📝 How to Use / 如何使用

- **每日笔记 (Daily Notes):** 在 `daily/` 目录下按日期命名（如 `2026-03-29.md`），记录当天学习内容。
- **专题笔记 (Topic Notes):** 在 `topics/` 下对应子目录中记录某一算法或数据结构的系统整理。
- **模板 (Template):** 参考 `templates/daily-template.md` 保持笔记格式统一。
